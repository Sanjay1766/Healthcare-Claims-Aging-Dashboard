=========================================================
TASK 1 - GOOGLE DRIVE CONNECTOR
=========================================================

Create a Python module called drive_connector.py.

Requirements:

1. Use Google Drive API with a Service Account.
2. Authenticate using a service_account.json file.
3. Accept a Google Drive Folder ID.
4. Find the most recently modified Excel file (.xlsx) in the folder.
5. Download the file locally into a downloads directory.
6. Return the downloaded file path.
7. Add proper logging.
8. Add exception handling.
9. Use:
   - google-api-python-client
   - google-auth

Expected Output:

latest_file_path = get_latest_excel_file(folder_id)

TASK 2 - EXCEL DATA LOADER
=========================================================

Create data_loader.py.

5. Standardize column names:
